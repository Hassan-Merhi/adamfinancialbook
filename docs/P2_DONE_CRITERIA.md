# P2 Done Criteria

P2 is complete only when implementation and release evidence are both finished.

Implementation done:
- shared UI semantics and presentation polish merged
- P2 WebKit UI/accessibility gate permanent in CI
- no accounting, migration, permissions, offline, or API behavior regression

Release done:
- all PR and post-merge main gates green
- exact final SHA live on Render and production certification green
- fresh encrypted backup tied to that final SHA delivered and acknowledged
- stable release tag created from the same certified SHA
